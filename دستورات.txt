راهنمای دستورات — هرکدوم رو تک‌تک کپی کن و تو پنجره‌ی cmd پیست کن (راست‌کلیک = پیست)، بعد Enter بزن.

============================================
قدم ۱: نصب کتابخونه‌ها (فقط بار اول لازمه)
============================================

python -m pip install --upgrade pip

pip install -r requirements.txt


============================================
قدم ۲: تنظیم توکن‌ها
============================================

قبل از قدم ۳، مطمئن شو فایل tokens.env رو با Notepad باز کردی
و سه خط توکن رو با مقادیر واقعی خودت پر کردی و Save کردی.


============================================
قدم ۳: اجرای ربات
============================================

python main.py


============================================
نکات
============================================

- برای متوقف کردن ربات، تو همون پنجره‌ی cmd بزن: Ctrl + C
- اگه خطا گرفتی، متن کامل خطا رو کپی کن و بفرست بررسی بشه
- هر دفعه که خواستی ربات رو دوباره اجرا کنی، فقط "قدم ۳" کافیه؛
  قدم ۱ رو دیگه لازم نیست تکرار کنی (مگر این‌که فایل‌های پروژه آپدیت بشن)
